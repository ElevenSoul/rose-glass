# Rose Glass

A Vencord theme that makes Discord look like a macOS Tahoe app, in muted dusty rose.

- Floating glass server dock and channel sidebar, with Mac traffic-light window buttons
- Frosted message bubbles, glass message bar and header buttons
- Mac-style Settings, menus, popups, switches, checkboxes and capsule buttons
- Springy animations (respects reduced motion)
- Follows Discord's light/dark setting

## Install

1. Download [`RoseGlass.theme.css`](https://raw.githubusercontent.com/ElevenSoul/rose-glass/main/RoseGlass.theme.css).
2. Put it in your Vencord themes folder (Vencord → Themes → **Open Themes Folder**).
3. Turn on **Rose Glass** in Vencord → Themes.

That file loads the theme from `https://elevensoul.github.io/rose-glass/rose-glass.css`, so you get updates automatically the next time Discord starts.

## Customize

Edit the settings at the top of your local `RoseGlass.theme.css`: highlight color, your own wallpaper, tint, blur, message bubbles on/off, roundness and gaps. Updates never overwrite them.

## Files

- `rose-glass.css`: the full theme (served through GitHub Pages)
- `RoseGlass.theme.css`: the small file you install, with your settings
- `preview/`: browser mockups of the design directions
